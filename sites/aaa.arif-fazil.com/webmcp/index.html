WebMCP

Browser → MCP Bridge. Call arifOS constitutional tools directly from the browser via SSE transport.

How It Works

Browser (fetch/EventSource)
  │  SSE or HTTP POST
  ▼
arifos.arif-fazil.com/mcp
  │  F1-F13 constitutional floors
  ▼
arifOS Kernel (:8088)
  │  19 canonical tools
  ▼
Response (JSON-RPC)

Connect

WebMCP uses the same MCP endpoint as any other client. From the browser, you can:

  • Call arif_ping — liveness probe
  • Call arif_sense_observe — search, ingest, map
  • Call arif_mind_reason — multi-step reasoning
  • All 19 tools, governed by F1-F13

Endpoint: https://arifos.arif-fazil.com/mcp

Transport: SSE (EventSource) or HTTP POST

Quick Start

// Connect via SSE
const es = new EventSource('https://arifos.arif-fazil.com/sse');
es.onmessage = (e) => console.log(JSON.parse(e.data));

// Or HTTP POST
const res = await fetch('https://arifos.arif-fazil.com/mcp', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    jsonrpc: '2.0',
    method: 'tools/call',
    params: { name: 'arif_ping', arguments: {} },
    id: 1
  })
});
