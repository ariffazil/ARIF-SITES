Build Your Own MCP App

Every app here uses the same pattern:

1. Connect to arifos.arif-fazil.com/mcp (SSE or HTTP POST)
2. Call arif_session_init to start a constitutional session
3. Use any of the 19 tools — F1-F13 governs every call
4. Render results in your browser

See /webmcp/docs for the full WebMCP guide.
