arifOS · MCP gateway explainer

The /mcp endpoint is a machine — not a page

If you reached this page, you clicked something labelled "MCP Gateway" expecting to read a webpage. The /mcp endpoint speaks JSON-RPC 2.0 to AI agents and MCP-aware tools — it does not render HTML for browsers, by design.

Why a browser gets a JSON error

The /mcp endpoint accepts only POST requests with Content-Type: application/json and a valid JSON-RPC envelope. A plain browser GET (which is what you did) violates the MCP transport spec and is rejected. This is correct behavior — it's the same reason /api/send-mail shouldn't render as a web page.

Per F9 ANTI-HANTU: we don't want to render a fake "200 OK with HTML" page just to satisfy browsers. That would be a false epistemic claim.

How AI agents connect

An MCP client sends a JSON-RPC envelope. Example tools/list call:

curl -X POST https://mcp.arif-fazil.com/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

For a full machine-readable surface listing, see /llms.txt, /.well-known/agent.json, and /mcp/explorer (the developer/audit catalog — engine room, not cockpit).
