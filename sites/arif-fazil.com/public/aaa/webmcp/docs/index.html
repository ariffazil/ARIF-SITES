WebMCP Documentation

How to build browser applications that call arifOS MCP tools.

Architecture

Browser (your app)
  |  fetch() or EventSource
  v
mcp.arif-fazil.com/mcp
  |  F1-F13 constitutional floors
  v
arifOS Kernel (:8088)
  |  19 tools
  v
JSON-RPC Response

HTTP POST

const res = await fetch('https://mcp.arif-fazil.com/mcp', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    jsonrpc: '2.0',
    method: 'tools/call',
    params: { name: 'arif_ping', arguments: {} },
    id: 1
  })
});

SSE Streaming

const es = new EventSource('https://arifos.arif-fazil.com/sse');
es.onmessage = (e) => console.log(JSON.parse(e.data));
